# 招标资料样本（demo）

## 项目目标
构建一个本地可运行的软件工厂缩小版，让开发者上传资料后自动生成需求三件套。

## 目标用户
- 主要用户：中小团队的研发与产品经理。
- 次要用户：需要快速整理客户诉求的售前。

## 关键流程
1. 上传或粘贴招标/需求资料。
2. 系统解析资料并给出就绪度评分与缺口。
3. 逐步生成 ORD / CRD / PRD 三件套并维护追溯矩阵。

## 约束
- 必须支持本地单机运行，不强依赖外网与云服务。
- API Key 等密钥需加密存储（AES-256-GCM）。
- 单工作区鉴权即可。

## 成功标准（验收）
- 上传资料到生成三件套初稿可在前端完整呈现。
- RTM 覆盖率报告可出，且覆盖率不低于 0.85。
- 需求自检三项（完备/一致/可测）全绿后可定稿。
